## iojogas

### What is this? 🤔 
A collection of web-based games, made with HTML, CSS, Javascript and Express.js.

### Where can I access it? 🖥
You can access it <a href="https://www.iojogas.com.br">here</a>

### How to run 🏃

     Clone the repository.
     Install dependencies using 'npm install'.
     Run the project with 'npm run dev'.
     Access http://localhost:3000 in your browser.
