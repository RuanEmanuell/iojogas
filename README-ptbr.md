## iojogas

### O que é isso? 🤔 
Uma coleção de jogos baseados na web, feitos com HTML, CSS, Javascript e Express.js.

### Onde posso acessá-lo? 🖥️
Você pode acessá-lo <a href="https://www.iojogas.com.br">aqui</a>

### Como executar 🏃

     Clone o repositório.
     Instale as dependências usando 'npm install'.
     Inicie o projeto com 'npm run dev'.
     Acesse http://localhost:3000 no seu navegador.
